# 油站设备巡检清单（异常整改闭环）

- 行业：石油
- 技术栈：React、Vite、TypeScript、Zustand、Ant Design
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

数据保存在浏览器 localStorage（键 `dfwlfront-10-inspection-v2`），刷新后巡检记录、区域锁定状态、整改进度与闭环信息保持一致。

## 闭环规则

1. 巡检结果分为「正常 / 异常」。选择「异常」时必须登记**整改责任人、整改期限、临时安全措施**，整改期限不得早于巡检（发现）日期。
2. 整改进度按 **待整改 → 整改中 → 已闭环** 单向推进：「开始整改」进入整改中；闭环必须填写**处理说明**，记录闭环时间。
3. 某区域存在未闭环异常时该区域被锁定：
   - 新增巡检记录不可选「正常」（下拉中禁用并提示）；
   - 新增巡检日期不得早于该区域最早异常的发现日期（日期控件限制 + 提交校验）；
   - 原异常记录的删除按钮禁用，不得移除。
4. 超过整改期限仍未闭环的异常在页面顶部红色横幅中计数并列出明细；「未闭环异常」指标同步高亮。
